Customer Support · Mock scenario, not a real ticket

Duplicate charge on one order

Overview

"I was charged twice for the same order — can someone look into this?"

Process

Investigation
Check payment processor logs to tell a true duplicate from a pending authorization that later posts.
Troubleshooting
Compare both charges to the order record and confirm the status of each before promising anything.
Resolution
Explain that one charge looks like a pending authorization that should drop off in 1–3 business days, and flag it with the payment processor to confirm.
Documentation
Record the processor flag and the follow-up promised to the customer.

Result / Outcome

The customer knows what to expect, and a genuine duplicate would be refunded right away.

Skills demonstrated

Communication, troubleshooting, problem solving, customer service, documentation, escalation handling.

Reply I'd send

"Thanks for catching this. I checked the payment records and it looks like one of the two charges is a pending authorization that should drop off within 1–3 business days, rather than an actual second charge — but I want to confirm that's really what happened, so I've flagged it with our payment processor. I'll follow up directly once I hear back, and if it's a genuine duplicate, I'll get that refunded right away."

Customer Support · Ecommerce · Mock scenario, not real tickets

Mock support inbox

Overview

Six realistic messages for an ecommerce scenario, each with what I'd check first and how I'd respond.

Tickets

Where is my order?

Six days, no shipping update. Check the order number, tracking, and whether the delay is carrier-side or a fulfillment miss. Flag with the carrier, follow up, and start a replacement or refund if it doesn't move.

Return or refund request

Item doesn't fit. Check the return window and whether the return is prepaid. Start the return, send a prepaid label, refund in 3–5 business days after check-in.

Product doesn't match description

Tag says wool blend, listing says stretch nylon. Cross-reference the description against item specifics, own the listing error, correct it, offer refund or exchange.

Shipping delay complaint (de-escalation)

Second late order, frustrated customer. Check order history for a repeating cause, acknowledge it, upgrade shipping at no charge, note the account.

Billing / charge dispute

See the duplicate charge case study.

Trust objection from a new seller's buyer

No reviews yet, is this legit? Offer tag and stitching close-ups and explain the return policy.

Ecommerce · Product Research

Pricing audit of a live eBay listing

Overview

Lululemon high-rise ankle leggings, women's size 6, pre-owned, thrift-sourced (cost about $8.00). I created the listing, then reviewed it as an ecommerce ops hire would.

Objective

Check the price against real market comps.

Process

Pulled six recently sold comps from eBay. The closest size/condition match sold for $30.40, near the $30 median, and comps ran $25–45.

Scenario Cost Shipping Fee Price Est. profit Margin
As listed $8.00 $4.50 $1.10 $6.00 −$7.60 −126.6%
Recommended reprice $8.00 $4.50 $4.14 $28.99 $12.35 42.6%

Tools

eBay, Google Sheets, Google Docs

Result / Outcome

At $6.00 the listing loses about $7.60 per sale. Repricing to $28.99 turns it into a profit while staying below retail.

Ecommerce · Product Listing

Listing QA: catching a wrong field

Overview

Listing title: "Lululemon Ankle Leggings Women's High Rise Size 6 Pink Yoga".

Process

Compared every item-specific field against the written description instead of assuming they matched. The Material field said "Wool Blend"; the description correctly said "stretch nylon blend."

Result / Outcome

Flagged for correction to "Nylon/Spandex Blend" before a buyer could raise it, removing a likely item-not-as-described claim.

Ecommerce Operations · Order Support

Order fulfillment workflow

Overview

A simulated sale of the same listing, with Best Offer accepted at $18.00, walked through the eight steps every order gets.

Process

  1. Best Offer accepted; order created with payment confirmed.
  2. Matched the order to the exact eBay item.
  3. Checked the shipping address and ZIP code.
  4. Re-checked the item against the listing photos.
  5. Packed in a poly mailer with a thank-you note.
  6. Generated the shipping label and attached tracking.
  7. Marked the order "Shipped" in eBay.
  8. Sent shipping confirmation with tracking.
